## WealthMe Database Schema

Tables:

- users
- families
- family_members
- accounts
- categories
- transactions
- investments
- investment_returns
- assets
- asset_history
- liabilities
- goals
- goal_progress
- ai_insights
- notifications

## Formulas

Net Worth = Cash + Investments + Assets - Liabilities

Savings Rate = (Income - Expense) / Income \* 100

ROI = (Current Value - Invested Amount) / Invested Amount \* 100

Goal Progress = Current Amount / Target Amount \* 100
