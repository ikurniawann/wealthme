# Twenty UX details audit

Scope: preserve the shipped WealthMe UI, reuse installed primitives, implement applicable frontend details sequentially, and verify each increment. Shared foundation edits are required by the explicitly requested app-wide interactions; no new library or backend change is planned.

## Acceptance and verification

- Skeleton reserves the same notification row layout and appears after 300 ms.
- Command palette exposes permitted routes and supported global actions with keyboard operation.
- Shortcut hints match the platform and shortcuts ignore editable fields.
- Reversible AI history deletion offers six-second undo before the request; failures restore the row.
- View transitions have a fallback, remain under 300 ms and honor reduced motion.
- Mobile sheets follow touch gestures and retain keyboard and close-button dismissal.
- Interruptible state animation preserves the current value and never blocks input.
- Touch targets reserve at least 48 × 48 CSS pixels on touch layouts.
- Headings balance, paragraphs use pretty wrapping, and squircle corners progressively enhance existing radii.

After each increment: repository QA, web type checking, relevant Jest tests and repository security gate. Full repository build/tests at the first and final increments. Browser checks cover desktop, mobile and reduced motion.
