# WealthMe

Personal Wealth Operating System

Version 1.0

## Overview

WealthMe adalah aplikasi Personal Wealth Management yang membantu pengguna mengelola:

- Dana Tunai
- Rekening Bank
- E-Wallet
- Investasi
- Aset
- Liabilitas
- Cash Flow
- Financial Goals
- Family Finance

Aplikasi berfokus pada pertumbuhan Net Worth (Kekayaan Bersih) dan bukan hanya pencatatan transaksi.

## Core Formula

Net Worth = Asset + Investment + Cash - Liability

## User Types

### Personal User

Mengelola keuangan pribadi.

### Family Owner

Mengelola group keluarga.

### Family Member

Mengakses group keluarga sesuai permission.
