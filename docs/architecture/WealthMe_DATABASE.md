- goals
- goal_progress
- ai_insights
- notifications

## Formulas

**Net Worth**

```
Net Worth = Cash + Investments + Assets - Liabilities
```

**Savings Rate**

```
Savings Rate = (Income - Expense) / Income * 100
```

**ROI**

```
ROI = (Current Value - Invested Amount) / Invested Amount * 100
```

**Goal Progress**

```
Goal Progress = Current Amount / Target Amount * 100
```
