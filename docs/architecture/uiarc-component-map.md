# WealthMe shared component → Arc UI map

Inventory date: 2026-10-05. Scope is the production source files directly in
`apps/web/src/components/{ui,wm,shell,charts}`; colocated tests are verification
assets, not shared component exports. Import fan-out is counted from TS/TSX
imports under `apps/web/src`, with the `@/components/wm` barrel counted once per
consumer module. Key consumers below are representative high-impact consumers.

## Arc evidence and decision vocabulary

Arc's public machine-readable catalog is
[`catalog.json`](https://uiarc.dev/r/catalog.json) (generated 2026-10-04;
234 items, 127 free). Candidate Markdown references use the per-item
`/components/<name>/markdown` URLs. The relevant docs were inspected for the
catalog candidates listed below; all of the minimum requested candidates
(button, input, textarea, dialog, dropdown-menu, context-menu, card, badge,
avatar, progress, skeleton, tabs, accordion, select/combobox, search-field,
money-input, date-picker, and chart candidates) are marked **free**. Arc's
[`llms.txt`](https://uiarc.dev/llms.txt) documents that items depend on a shared
foundation (including semantic tokens and CSS modules), that items may add
Motion and Radix dependencies, and that Pro sources are licensed and must not
be reconstructed. A one-off fetch for Scroll area Markdown failed; catalog
metadata confirms it is free and dependency-free, so no source-level claim is
made for it.

- `adopt`: use a free Arc item behind the current WealthMe API after a focused
  compatibility and parity check.
- `adapt`: retain the WealthMe API and behavior through a translation wrapper
  around a semantically suitable free Arc implementation.
- `retain`: keep WealthMe implementation because there is no direct candidate
  or parity is not established.
- `replace-with-free`: replace a local implementation with a documented free
  Arc item only after preserving its public API and behavior.
- `prohibited`: a Pro-only/source-licensed candidate without established
  entitlement, or an unsafe wholesale replacement, is excluded.

No Arc Pro entitlement was evidenced in repo configuration or the task inputs.
Arc foundation CSS is not approved for global import: the migration spec
requires one token authority and a scoped compatibility spike first. `DESIGN.md`
is non-blocking per the approved spec; token/theme collision remains a recorded
risk, not a stop condition.
