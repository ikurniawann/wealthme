**StatusBadge** — soft-fill status pill for tables, goal rows, and account lists. Set `dot` for a leading status dot.

```jsx
<StatusBadge variant="success" dot>On track</StatusBadge>
<StatusBadge variant="warning" dot>Perlu dorongan</StatusBadge>
```

Variants: `success` · `danger` · `warning` · `info` · `purple` · `gray`.
